# Changelog

## 3.0 — 2026-09-14

First public release at [Tia-Lin/PongFetch](https://github.com/Tia-Lin/PongFetch), tag `v3.0`.

- Current validated three-part mechanical kit: integrated-latch frame, locating-skirt collet and removable screw cap.
- Eight side-release latches with four net pins each, shallow blended net guides, and three internal first-layer breakaway ties per flap.
- Flat 1.2 mm fin bases and smooth fin-root and handle-mount transitions.
- Flush two-colour labels readable after assembly: PongFetch / Pick.Play. / open source / rev 3.0.
- Latest saved frame and handle-parts 3MF projects, three STL meshes, editable OpenSCAD files, assembly and printing documentation.
- CC BY-NC-SA 4.0 design license, attribution and third-party notices.
- Generated download packages are release assets, not duplicate tracked files.

Publication does not change existing mechanical geometry or saved print settings. The mechanical baseline has physical print feedback; new colour finish and long-term durability are not certified. Earlier private prototype revisions are not included in this repository's public history.
