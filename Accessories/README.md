# Accessories

Optional accessories for the **free end** of the PongFetch PVC handle. Choose the decorative cap or the removable hanger; both target a pipe with **21.34 mm actual outside diameter**.

| Accessory | Ready-to-slice project | Assembly and source |
| --- | --- | --- |
| End cap with flush paddle-and-ball logo | [End cap 3MF](EndCap/PongFetch_EndCap_Logo_X2D_PETG_Basic.3mf) | [EndCap](EndCap/README.md) |
| D removable hanger and compression nut | [Hanger 3MF](Hanger/PongFetch_Hanger_X2D_PETG_Basic.3mf) | [Hanger](Hanger/README.md) |

The end cap uses the user-selected **ID 21.44 mm / OD 23.84 mm / 1.20 mm wall** fit. It is decorative and is not a hanging attachment. The hanger clamps onto the tube without glue or drilling and releases by loosening its nut. The user has reported successful use of both designs; the hanger is not load-rated.

Both projects save **X2D, 0.4 mm nozzle, textured PEI, PETG Basic, 0.20 mm layers and four requested walls, supports disabled**. Open them in Bambu Studio, select the actual printer and spools, then re-slice. They contain no machine-ready G-code. The end cap is a single object with two colour parts; the hanger project contains its two separate printable pieces.

STLs, editable OpenSCAD source and compact verification records are included in each folder. EndCap source is standalone; Hanger source requires separately installed BOSL2. Trial directories and older fit variants have been removed from the active release.

Download the standalone **PongFetch_Accessories.zip** or the complete **PongFetch_Rev3_Maker_Bundle.zip** from the [rev 3.0 release](https://github.com/Tia-Lin/PongFetch/releases/tag/v3.0). The original core tag is unchanged; refreshed bundles identify their source commit in `PACKAGE_INFO.json`.
